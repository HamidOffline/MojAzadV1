# 🌊 MojAzad VPN

**MojAzad (موج آزاد)** یک کلاینت VPN متن‌باز برای Android است که با تمرکز روی اتصال ساده، مدیریت سرورها، انتخاب خودکار سرور مناسب و پایداری اتصال توسعه داده شده است.

> Current Version: **MojAzad V3 — 3.0.0**

---

## ✨ امکانات

- 📡 پشتیبانی از Subscription
- 📚 پشتیبانی از چند Subscription
- 📋 افزودن Subscription از Clipboard
- ⚡ تست Real Ping سرورها
- 🏆 انتخاب خودکار بهترین سرور بعد از Real Ping
- 🔌 اتصال خودکار به بهترین سرور
- 🔄 Auto Failover برای جابه‌جایی خودکار هنگام بروز مشکل
- 🟢 نمایش وضعیت سلامت سرورها
  - Excellent
  - Good
  - Weak
  - Offline
- 📱 نمایش دو ستونه سرورها به‌صورت پیش‌فرض
- 🔔 In-App Update از GitHub

---

## 📊 Connection Dashboard

هنگام اتصال، اطلاعات مهم اتصال به‌صورت لحظه‌ای در Dashboard نمایش داده می‌شود:

- Server Name
- Country / IP
- Ping
- Health
- Download
- Upload
- Connection Duration

## 📥 دانلود

آخرین نسخه MojAzad را از بخش **Releases** همین مخزن دانلود کنید.

نسخه‌های موجود:

- `arm64-v8a` — مناسب اکثر گوشی‌های Android جدید
- `armeabi-v7a` — برای دستگاه‌های ARM قدیمی‌تر
- `x86`
- `x86_64`
- `Universal` — اگر معماری دستگاه خود را نمی‌دانید

اگر مطمئن نیستید کدام نسخه مناسب دستگاه شماست، **Universal** را دانلود کنید.

## 🛠 اطلاعات فنی

- Package ID: `com.mojazad.vpn`
- Android Version: `3.0.0`

  - ARM64
  - ARM 32-bit
  - x86
  - x86_64
  - Universal
